About the Project & Methodology

B.Sc Data Science Academic Project Documentation & Viva Preparation Guide

1. Project Overview & Problem Statement

The Mumbai Local Development Dashboard — Ward-Level Visualization is an academic Data Science web application developed to analyze and visualize municipal development indicators across the 24 administrative municipal wards of Mumbai.

Problem Statement: While municipal and census data for Greater Mumbai is published across several reports and portals, it is frequently siloed in dense PDF tables and disjointed municipal releases. Citizens, researchers, and students lack a unified, beginner-friendly data platform to benchmark infrastructure, health, education, and sanitation equity at the ward level.

Project Goal: Execute an end-to-end Data Science pipeline:
Data Collection → Data Cleaning → Normalization → Sub-Indicator Feature Engineering → Composite Scoring → Interactive Visualization → Web Interface.

All baseline demographic, geographic, and municipal indicators are sourced from authentic public records:

Ethical Presentation Rule: This project strictly avoids subjective labels such as "bad" or "backward area." Differences in indicator sub-scores reflect relative municipal access and population density pressure.
3. Normalization & Scoring Mathematical Model
A. Why Normalization is Necessary

Indicators are recorded across vastly different measurement scales: population exceeds 900,000 in suburban wards, road length is measured in kilometers, while public facility counts range from 10 to 400. Direct summation would cause high-magnitude variables to disproportionately dominate the index.

Normalized Value = (Value - Minimum) / (Maximum - Minimum)
Transforms all metrics linearly into a standard 0 to 1 domain.
B. Composite Development Score Formula

The composite Development Score is calculated as an explainable weighted linear sum of six standardized municipal pillars (scaled from 0 to 100):

Development Score = (0.25 × Infrastructure) + (0.20 × Health) + (0.20 × Education) + (0.15 × Sanitation) + (0.10 × Environment) + (0.10 × Public Services)
C. Project-Defined Categorization Thresholds
  • High Development: Composite Score ≥ 65.0
  • Moderate Development: 45.0 ≤ Composite Score < 65.0
  • Low Development: Composite Score < 45.0 (Identified as priority areas for facility expansion)
4. Viva Voce 5-Minute Explanation Script
Q1. What is this project in one sentence?

"It is an end-to-end Data Science web dashboard that cleans, normalizes, analyzes, and visualizes civic infrastructure and public service indicators across Mumbai's 24 administrative municipal wards."

Q2. What Data Science algorithms or techniques did you apply?

"We utilized Pandas and NumPy for missing value verification, population density adjustment, feature engineering of per-capita civic facilities, Min-Max normalization, weighted linear index computation, and Pearson correlation analysis."

Q3. Why did you use Flask instead of a heavy framework?

"Flask is lightweight and beginner-friendly. It allows our Python data analysis logic (Pandas/NumPy) to directly communicate with HTML5/Chart.js frontends without over-engineering."

Q4. Is the Development Score an official ranking?

"No, it is explicitly a project-defined analytical index designed for educational benchmarking, and we have clearly documented all indicator weights and assumptions."

Technology Stack
  • Data Science: Python 3, Pandas, NumPy, Matplotlib
  • Web Backend: Flask (Python WSGI)
  • Frontend: HTML5, CSS3, JavaScript (ES6)
  • UI Framework: Bootstrap 5.3
  • Charts: Chart.js 4.4
  • Database: MySQL + mysql-connector-python
  • Reporting: Microsoft Excel & Power BI
Project Limitations
  • Census population figures represent official baseline figures; informal settlements experience continuous flux.
  • Indicator weights are analytical choices based on civic domain study, not government policy mandates.
  • Statistical correlation does not necessarily imply direct causation.
Future Scope
  • Incorporate time-series multi-year trends to visualize year-over-year civic progress.
  • Integrate high-resolution GIS shapefiles using GeoPandas / Leaflet.
  • Automate live municipal data ingestion via government open-data APIs.
  • Add citizen feedback sentiment analysis as a qualitative development metric.
